# AnixWeb (GitHub-версия)

Неофициальный браузерный клиент Anixart. Статический сайт: `index.html`, `assets/`, `sw.js`.

## Как развернуть

1. Залейте содержимое на GitHub Pages (или любой статический хостинг).
2. Откройте сайт, залогиньтесь.

## Комментарии и прокси

**Читать** комментарии, голосовать за них, добавлять в друзья — работает без ничего.

**Отправлять** комментарии нельзя без прокси: API Anixart отдаёт `402`, если в запросе нет заголовка `User-Agent: AnixartApp/...`, а браузер подставить этот заголовок физически не может (forbidden header).

Решение — маленький PHP-скрипт на **вашем** сервере, который подставит User-Agent. Готовый скрипт — `proxy.php` рядом.

### Шаги

1. Скачайте `proxy.php`, положите на свой PHP-хостинг. Убедитесь, что он открывается по HTTPS и отвечает JSON.
2. На сайте откройте **Настройки** (`?p=settings`).
3. Вставьте URL вашего скрипта (например `https://ваш-сайт/proxy.php`).
4. Сохраните. После этого появится поле для комментариев.

Без прокси сайт продолжает работать: чтение комментов, лайки, друзья, коллекции.

## Безопасность прокси

`proxy.php` — открытый CORS-прокси к API Anixart. Разрешает только хосты `api-s.anixsekai.com`. Ключи/токены пользователя через него не проходят (они в URL и передаются как есть). Рекомендуется не афишировать URL, либо добавить ограничение по `Origin`.
